These are the TeX sources of the AI-written manuscript ECM1.

Run these commands from this directory using a TeX distribution with the required packages:

pdflatex -interaction=nonstopmode -halt-on-error ECM1.tex
biber ECM1
pdflatex -interaction=nonstopmode -halt-on-error ECM1.tex
pdflatex -interaction=nonstopmode -halt-on-error ECM1.tex

The published PDF is in the parent directory.

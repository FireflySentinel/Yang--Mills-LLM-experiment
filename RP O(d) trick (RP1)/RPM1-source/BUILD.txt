TeX source of the AI-written manuscript RPM1.

This package contains one complete manuscript TeX file and its required supporting files.
Copy the package into a temporary directory outside the repository. Run the commands there.
Keep the resulting PDF and generated bibliography, then remove the temporary directory.

pdflatex -no-shell-escape -interaction=nonstopmode RPM1.tex
biber RPM1
pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error RPM1.tex
pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error RPM1.tex
pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error RPM1.tex

# EXPERIMENTAL BRANCH

**NEVER PR WITHOUT EXPLICIT CLEAR PERMISSION.**

The `major-refractoring` branch contains experimental mathematical changes.
The user requires explicit, clear permission before opening a pull request for
this branch or changes taken from it. This includes draft pull requests.

- Permission to research, edit, review, test, commit, create a fork, prepare PR
  text, or push does **not** authorize opening a PR.
- Instructions such as "continue", "prepare the contribution", or "commit"
  do **not** authorize opening a PR. Permission must explicitly cover that PR.
- This restriction applies to the main agent, subagents, background work,
  orchestration, and automatic continuation. Renaming the branch or moving its
  changes to another branch does not remove the restriction.
- Existing restrictions on pushes and other external actions remain in force.
  Adding this warning grants no permission to push or open a PR.

用户要求：这是实验分支。没有明确、清楚、覆盖该 PR 的许可，绝对不能开 PR，
包括 draft PR；允许修改、commit 或 push 均不等于允许开 PR。

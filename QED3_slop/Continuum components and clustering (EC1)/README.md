### Setting

Let $`V`$ be a finite-dimensional real inner-product space with an orthogonal representation $`\rho:O(3)\to O(V)`$. Let $`\mathcal X=\mathcal S'(\mathbb{R}^3;V)`$, equipped with the sigma-algebra generated by evaluations. For $`g(x)=Qx+b`$, use

```math
(g\cdot f)(x)=\rho(Q)f(Q^{-1}(x-b)),\qquad
 (g\cdot F)(f)=F(g^{-1}\cdot f),\qquad
 \widehat g A(F)=A(g^{-1}\cdot F).
\tag{1}
```

Write $`U(a)=\widehat{\tau_a}`$. For open $`O\subset\mathbb{R}^3`$, let $`\Sigma_O`$ be generated by $`F(f)`$ with real $`f\in C_c^\infty(O;V)`$. For a reflection $`r`$, put $`\mathcal R_r=\widehat r`$. An $`r`$-invariant law $`\lambda`$ is reflection positive on an open side $`H^+`$ if

```math
\mathbb{E}_\lambda[\overline{\mathcal R_r A}\,A]\ge0
```

for finite character sums $`A=\sum_bz_be^{iF(f_b)}`$ with real $`f_b\in C_c^\infty(H^+;V)`$. The positive sides below are chosen by making the displayed linear coordinate function positive.

**Theorem A (Components and clustering).**

Let $`\lambda`$ be a translation-invariant probability law on $`\mathcal X`$, invariant and reflection positive at the nine planes

```math
x_j=0\quad(1\le j\le3),\qquad
 x_j-x_k=0,\quad x_j+x_k=0\quad(1\le j<k\le3).
\tag{2}
```

Let $`\mathcal I`$ be the translation-invariant sigma-algebra, with invariance understood modulo $`\lambda`$-null sets, and let $`P=\mathbb{E}_\lambda[\,\cdot\mid\mathcal I]`$. Then

```math
\langle A,U(a)B\rangle_{L^2(\lambda)}
 \longrightarrow\langle A,PB\rangle_{L^2(\lambda)}
 \qquad(|a|\longrightarrow\infty)
\tag{3}
```

for every $`A,B\in L^2(\lambda)`$.

There is a unique translation-ergodic decomposition $`\lambda=\int\lambda_\xi\,\mathrm{d}\nu(\xi)`$, understood as the distribution of its conditional law on $`\mathcal X`$. On one common $`\nu`$-full set, every $`\lambda_\xi`$ is translation ergodic, invariant and reflection positive at every real translate of the planes in (2), and

```math
\langle A,U(a)B\rangle_{L^2(\lambda_\xi)}
 \longrightarrow
 \overline{\mathbb{E}_{\lambda_\xi}A}\,\mathbb{E}_{\lambda_\xi}B
 \qquad(|a|\longrightarrow\infty)
\tag{4}
```

for every $`A,B\in L^2(\lambda_\xi)`$. Reflection positivity holds on the entire positive-side $`L^2(\lambda_\xi)`$ space. These component laws are cubically invariant.

If in addition, for some fixed $`C\ge0`$,

```math
\mathbb{E}_\lambda e^{F(f)}\le e^{C\|f\|_2^2/2}
 \qquad(f\in\mathcal S(\mathbb{R}^3;V)\text{ real}),
\tag{5}
```

then the common full-measure set above may be chosen so that every component in it satisfies (5) with the same $`C`$, simultaneously for all real tests. Any specified measurable event of full $`\lambda`$-measure has full measure in almost every component.
